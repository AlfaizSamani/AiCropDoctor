PURPOSE AND LIMITS

About and help

An educational prototype for exploring image classification and responsible uncertainty.

The model is a screening aid

The app uses a server-side PyTorch EfficientNet-B5 image classifier. A model label is only a possible match, not a confirmed disease diagnosis.

Model: {{ model_id }} revision {{ model_revision }}

Original model source: ShyamSriKarthik/Plant-Disease-Detection

Technology stack: Flask, PyTorch, Torchvision

Supported image classes are determined by the configured model revision; see Learn for the current class list.

Known limitations

  • The model was trained on curated data and may not generalize to local field photos, different varieties, lighting or other plant conditions.
  • The displayed raw score is not a calibrated probability. No local field accuracy result is claimed.
  • Images are analysed server-side. The model is not bundled into the PWA and offline inference is unavailable.
  • No disease-specific treatment or pesticide recommendation is provided. Consult a qualified agricultural advisor.

Frequently asked questions

How accurate is this app?

No app-specific or local accuracy measurement is available. The result is an educational screen only.

Do my spoken symptoms affect the model?

No. Voice is transcribed to an optional note. The classifier analyses the image only.

Are my photos or history saved?

The photo is sent to the app server for inference and is not retained as an app case record. Werkzeug may temporarily spool larger uploads to host temporary storage; retention and cleanup depend on the host. Optional result history stays in browser storage and excludes photos.

Can the installed app diagnose offline?

No. Only the user interface shell may be cached; diagnosis requires the Flask backend and model.

Do not select or apply pesticides based only on a model result. Similar leaf symptoms may have different causes.

Getting started

A practical guide for starting the app, using it on a laptop or phone, and understanding what stays online or offline.

Requirements

  • Python 3.10 or 3.11 and the project dependencies.
  • Internet access for installing packages and the first model download.
  • Enough memory and disk space for the Transformers/PyTorch stack and model cache.

Windows laptop

From the repository folder, launch the included startup script. It creates the environment, installs dependencies and starts Flask.

.\START_WINDOWS.bat

On the same laptop open http://127.0.0.1:5000. Keep the terminal open while using the app; press Ctrl+C to stop Flask.

Manual PowerShell setup

py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install torch==2.6.0 torchvision==0.21.0 --index-url https://download.pytorch.org/whl/cpu
python -m pip install -r requirements.txt
python app.py

If the launcher cannot find Python, install Python 3.10/3.11 and use py -3.10 if needed; then reopen PowerShell.

macOS and Linux

Use Python 3.10 or 3.11. In a terminal, create and activate a virtual environment, install CPU PyTorch and project dependencies, then start Flask:

python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install torch==2.6.0 torchvision==0.21.0
python -m pip install -r requirements.txt
python app.py

Using a phone

A phone’s localhost points to the phone itself, not your laptop.

Recommended: HTTPS

Deploy the Flask app behind an HTTPS host, then open that actual HTTPS URL on the phone. Android Chrome can offer Install app/Add to Home screen; desktop installation depends on browser support.

Same-Wi-Fi development only

For LAN testing only, start Flask listening on 0.0.0.0 and use the laptop’s local IP and port from the phone. You may need a firewall rule. Plain http://192.168.x.x:5000 is not a secure context and may block camera, microphone or PWA installation; use HTTPS or a trusted local HTTPS setup for those features.

The service worker caches the UI shell only. Diagnosis still requires the Flask server and model to be reachable; installing the PWA does not make AI inference work offline.

Troubleshooting

Python command not found
Install Python 3.10 or 3.11 with the launcher, then restart the terminal. Verify with py --version.
Dependency installation fails
Check network access and Python version; retry the command shown above. Do not continue if package installation reports errors.
First analysis is slow / model unavailable
The model downloads on first analysis. Check internet access, available disk/memory, and the Flask terminal for errors; retry after connectivity returns.
No internet connection
The app shell may open if previously cached, but model download and diagnosis need a reachable backend. Restore connectivity and retry.
Port 5000 is already in use
Stop the other local service or set PORT to another unused port before starting Flask; open the matching local URL.
Photo rejected or too large
Use a readable JPG, PNG or WEBP up to 4 MB, with enough resolution and a clear leaf.
Microphone unavailable
Allow microphone access in browser settings and use localhost/HTTPS. Browser APIs vary. Speech recognition may send audio to an external browser service; type the note if it is unavailable.
Speech recognition unsupported
Use a supported browser if available, or type the note. The image analysis works without speech.
No voice for this language
Spoken read-out needs a locally available language voice. Install a compatible operating-system voice if available; otherwise use the written result.

Privacy and demo checklist

  • The selected photo is sent to the Flask server for inference. The app does not retain it as a case record, but Werkzeug may temporarily spool larger uploads to host storage while parsing the request; cleanup and retention depend on the host.
  • Symptom text is submitted with the request but does not affect the image classifier; avoid entering identifying or sensitive details.
  • History is optional, stored in this browser only, and excludes photos. Use My History to clear records.
  • Voice transcription can use an external browser service; audio is not recorded or stored by this app.
  • The app does not request location.
